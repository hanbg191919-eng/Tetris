# TETRIS + Basic

화면정의서와 기획명세서를 바탕으로 만든 React 기초 테트리스입니다.

## 실행

가장 간단한 실행 방법은 폴더의 `테트리스.html`을 더블클릭하는 것입니다. 별도 서버 없이 웹브라우저에서 바로 실행됩니다.

코드를 수정한 뒤에는 아래 명령으로 `dist` 파일을 다시 생성합니다.

```bash
npm install
npm run build
```

개발 중 자동 새로고침이 필요할 때만 `npm run dev`를 사용합니다. 검증 명령은 `npm test`입니다.

## 코드 리뷰 순서

1. `src/game.js`: React와 무관한 게임 규칙
2. `src/App.jsx`: 게임 상태, 입력, 타이머, 화면 전환
3. `src/styles.css`: 명세의 네이비/골드 화면 스타일과 반응형 처리
4. `test/game.test.js`: 핵심 규칙의 자동 검증

## 상태 흐름

- `board`: 바닥에 고정된 블록만 저장합니다.
- `piece`: 현재 움직이는 블록입니다.
- `queue`: 7-bag에서 뽑은 다음 블록 목록입니다.
- `hold`: 보관한 블록, `canHold`: 현재 턴에 홀드를 썼는지 여부입니다.
- `score`, `lines`: 점수와 제거한 줄 수이며, 레벨은 `Math.floor(lines / 10) + 1`로 계산합니다.
- `screen`: `home`, `playing`, `paused`, `gameover`, `ranking`, `settings` 중 하나입니다.

한 틱마다 아래 이동을 시도하고, 실패하면 현재 블록을 보드에 합칩니다. 이후 완성 줄을 지우고 점수를 계산한 다음 다음 블록을 생성합니다. 새 블록이 생성 위치에서 바로 충돌하면 게임 오버입니다.

## 구현 범위

완료: 10×20 보드, 7종 블록, 7-bag, 이동/회전/소프트·하드드롭, 고스트, 줄 삭제, 점수/레벨, HOLD/NEXT, 일시정지, 게임오버, 로컬 TOP 10, 모바일 버튼.

기초 버전에서 제외: 아이템 인벤토리와 아이템 효과, 스킬 게이지와 스킬 효과, 서버 랭킹, 사운드 파일. 이 기능들은 코어 게임 규칙과 화면을 분리했기 때문에 후속 모듈로 추가할 수 있습니다.
